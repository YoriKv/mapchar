# mapchar-lint

Static checks for hand-edited `.mapchar` project files: what a load would
silently drop, ignore or misread.

```bash
PYTHONPATH=src python3 -m mapchar_lint path/to/project.mapchar
```

Standard library only. [`docs/lint.md`](../../docs/lint.md) in the mapchar
repository covers the options, the codes, the snapshot and the tests.
